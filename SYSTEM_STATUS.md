### ✅ ARCHITECTURE DECISIONS MADE

**Backend Model:**
- PluggedIN is the invisible backend (agents run here)
- Results sync to client's CRM (HubSpot, Salesforce, Airtable, or Twenty)
- Client never sees PluggedIN portal (optional dashboard only)
- Results flow directly to their system of record

**Pricing:**
- Starter: £1,297/month (1 service)
- Growth: £2,497/month (3 services)
- Scale: £4,997/month (all 8 services)
- Empire OS: £2,497-£20,000+/month (multi-business)

**CRM Integration (Tiered):**
1. Client has HubSpot/Salesforce/Pipedrive → sync directly
2. Client has Airtable → sync directly
3. Client has nothing → we provide free Twenty instance (or Airtable)
4. Custom → webhook API available
