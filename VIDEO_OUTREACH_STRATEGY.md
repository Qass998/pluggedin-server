## THE INSIGHT

**Traditional outreach:**
"Hi [Name], I help companies get leads. Want to chat?"
→ Response rate: 2-3%

**Video outreach (PluggedIN):**
[Send personalized video showing their specific opportunity]
→ Expected response rate: 15-25% (working demo beats copy)

**Why it works:**
- Shows you analyzed them (credibility)
- Shows you understand their business (relevance)
- Shows the outcome working (proof)
- Removes friction (they see results before committing time)

## BACKEND WORKFLOW: HOW THIS SCALES

### Trigger: Prospect found
1. **Analyze prospect** (company size, industry, signals)
2. **Select template** (ecommerce? trades? SaaS? legal?)
3. **Gather data** (scrape, research, benchmarks)
4. **Generate script** (Claude → tailored 11Labs script)
5. **Create video** (Remotion with template + data)
6. **Voiceover** (11Labs text-to-speech)
7. **Send email** (personalized with video link)

### API endpoint (backend):
```
POST /api/leads/{id}/generate-video
{
  "vertical": "ecommerce",
  "prospect": {
    "name": "John",
    "company": "Acme Store",
    "industry": "dropshipping",
    "website": "acmestore.com"
  }
}

Response:
{
  "success": true,
  "video_url": "https://videos.pluggedin.io/...",
  "email_draft": "Subject: I analyzed your competitors...",
  "script": "Hey [Name], I analyzed 8 of your top competitors..."
}
```

### Time to generate: 2-3 minutes per video
- Data gathering: 30 seconds
- Script generation: 30 seconds
- Video generation (Remotion): 60-90 seconds
- Email draft: 10 seconds

## INTEGRATION WITH OUTREACH

Instead of:
```
POST /api/leads/find
{
  "country": "UK",
  "niche": "ecommerce",
  "limit": 50
}

Response:
{
  "leads_found": 50,
  "leads": [...]
}
```

Now:
```
POST /api/leads/find-and-video
{
  "country": "UK",
  "niche": "ecommerce",
  "limit": 50,
  "include_video": true
}

Response:
{
  "leads_found": 50,
  "leads": [
    {
      "name": "Store A",
      "email": "owner@storea.com",
      "video_url": "https://...",
      "email_draft": "...",
      "ready_to_send": true
    },
    ...
  ]
}
```
